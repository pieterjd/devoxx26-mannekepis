# Manneke Pis Mood Check

A Spring Boot form for rating how pissed off the user is, with Belgian styling and a Manneke Pis visual backdrop. Each submission is saved to PostgreSQL.

## Run PostgreSQL locally

```bash
docker compose up -d postgres
```

## Start the application

```bash
./mvnw spring-boot:run
```

Then open http://localhost:8080 in your browser.
